# The Crystal Village: Git & GitHub Adventure Flow

## Overview
The application has been restructured so that the **Masters are allies, teachers, and mentors**, while the **combat challenges are fought against corrupted Git Glitch Monsters** blocking the forward path. The entire curriculum is now focused on **Git & GitHub**.

---

## 2. The 5 Chapters: Git Mentors, Lectures, & Monsters

### Chapter I: The Repository Gate
- **Location:** The Staging Courtyard
- **Mentor:** **Master Linus** (*The Git Sage*)
- **Git Lesson:** Git Fundamentals & The Three Trees (Working Directory, Staging Area, Git Repository snapshots, `git init`, `git add`, `git commit -m`)
- **Boss Monster:** **The Unstaged Glitch** (*Specter of Lost Work*)
- **Combat Questions:** Working Directory vs Staging Area (`git add`) and commit role.

### Chapter II: The Branching Grove
- **Location:** The Branching Grove
- **Mentor:** **Master Octavia** (*The Branch Weaver*)
- **Git Lesson:** Branch Isolation, Switching, & The `HEAD` Pointer (`git branch`, `git switch -c`, `HEAD` concept)
- **Boss Monster:** **The Detached HEAD Phantom** (*Wraith of the Lost Pointer*)
- **Combat Questions:** Modern branch creation commands (`git switch -c`) and what `HEAD` represents.

### Chapter III: The Remote Chasm
- **Location:** The Cloud Bridge
- **Mentor:** **Master Hub** (*The Remote Shepherd*)
- **Git Lesson:** GitHub Remotes, Origin, Cloning, Pushing, & Pulling (`git clone`, `git push -u origin main`, `git pull`)
- **Boss Monster:** **The Push-Rejected Golem** (*Non-Fast-Forward Fiend*)
- **Combat Questions:** Handling `[rejected - non-fast-forward]` errors and cloning remote repositories.

### Chapter IV: The Merging Chasm
- **Location:** The Conflict Gorge
- **Mentor:** **Master Resolv** (*The Merge Arbiter*)
- **Git Lesson:** Merging, Pull Requests, & Resolving Conflicts (Fast-Forward vs 3-Way, `<<<<<<< HEAD`, `=======`, `>>>>>>>`, PR review)
- **Boss Monster:** **The Merge-Conflict Chimera** (*Beast of Clashing Diffs*)
- **Combat Questions:** Reading conflict markers and staging/committing the resolved file.

### Chapter V: The Grand Version Sanctum
- **Location:** The Prime Crystal Core
- **Mentor:** **Grandmaster Octocat** (*Keeper of Git History*)
- **Git Lesson:** Git Time Travel & Safe Rollback (`git log --oneline`, `git stash`, `git revert` vs destructive `git reset --hard`)
- **Boss Monster:** **The Corrupted History Leviathan** (*Devourer of Git Logs*)
- **Combat Questions:** Safe rollback on shared branches (`git revert`) and temporary code shelving (`git stash`).

## 3. Hall of Git Trials & 100-Answer Milestone
- Accessible anytime from the HUD (`Trials Arena`).
- Draw from a 20-question bank spanning Git concepts: `.gitignore`, `git blame`, `git cherry-pick`, `git tag`, `git diff`, Forks, PRs, SSH keys, `--amend`, and rebasing.
- Reaching 100 correct answers activates the **Prime Crystal Awakening** cinematic, conferring the title **"Grand Archon of the Git Repository"**.
